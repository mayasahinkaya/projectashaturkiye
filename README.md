# Project A.S.H.A. Türkiye

A static, bilingual website for the Türkiye chapter of Project A.S.H.A., a youth-led initiative raising awareness about human trafficking and educating young people about prevention.

## Open locally

Open `index.html` in a browser. No build step or dependencies are required.

## Editing guide

- **Team names:** open `team.html` and replace `Your name here` and each `Name to add`.
- **Team photos:** in `team.html`, replace a `<div class="portrait-placeholder">...</div>` with an image, for example: `<img class="portrait-placeholder" src="images/lead.jpg" alt="Chapter lead name">`. Create an `images` folder next to the HTML files and put your own images there.
- **Events:** open `events.html` and replace the `.empty-events` content when an event is ready. Include its date, location, partner, description, and registration link.
- **Application form:** open `join.html` and replace `https://forms.google.com` with your real Google Form, Microsoft Form, or other application URL.
- **Instagram:** replace the two `https://instagram.com` links with the chapter's actual Instagram URL.
- **Text:** each visible phrase has English and Turkish versions in `data-en` and `data-tr` attributes. Edit both attributes to keep the language toggle accurate.
- **Language:** the site opens in English by default and remembers the visitor's last choice using local storage.

The design intentionally uses no stock or AI-generated photography. Add your own photographs only after receiving appropriate consent, especially for minors.
